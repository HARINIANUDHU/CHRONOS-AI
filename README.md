# CHRONOS-AI — SIH Prototype

AI-Driven Spatio-Temporal Tracking of Extreme Weather Anomalies in Medium-Range Forecasts.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

This prototype uses synthetic demonstration data. Replace `make_data()` with validated
forecast data and a trained spatio-temporal model before making operational claims.
